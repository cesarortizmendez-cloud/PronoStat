📄 Informes automáticos Versión 3

Genera un resumen integral del conjunto de datos cargado (perfil por columna, correlaciones y hallazgos) y descárgalo como informe Excel con un clic.

📘 Manual de utilización del módulo

¿Qué hace este módulo? Genera automáticamente un resumen integral del conjunto de datos y lo exporta como informe Excel.

¿Cómo se usa? Con un dataset cargado, pulsa «Generar informe»; luego «Descargar informe Excel» para guardar el archivo.

¿Cómo se interpretan los resultados? El perfil por columna resume cada variable (media, dispersión, atípicos). El mapa de calor de correlaciones muestra qué variables se relacionan (verde = positiva, rojo = negativa; más intenso = más fuerte). Los hallazgos destacan lo más importante en palabras.
