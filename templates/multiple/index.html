📚 Pronóstico por lotes

En la práctica rara vez se pronostica una sola serie: se automatiza el proceso para cientos de ítems. Este módulo ejecuta el modelo elegido sobre cada columna seleccionada y reporta el pronóstico y su exactitud (MAPE/MASE).

📘 Manual de utilización del módulo

¿Qué hace este módulo? Aplica el mismo modelo de pronóstico a muchas series a la vez (pronóstico por lotes), útil para carteras de productos, sucursales o SKUs.

¿Cómo se usa? Elige el modelo, el horizonte y marca las series (columnas) a pronosticar; pulsa «Pronosticar todas».

¿Cómo se interpretan los resultados? La tabla muestra el pronóstico de cada serie y su exactitud (MAPE/MASE). Revisa las series con mayor error: pueden requerir otro modelo o más datos.
